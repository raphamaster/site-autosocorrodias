# Auto Socorro Dias — Landing Page

Landing page estática criada para a Auto Socorro Dias, com foco em contato por WhatsApp e telefone.

## Estrutura

- `index.html`: conteúdo e HTML semântico
- `styles.css`: layout e responsividade
- `script.js`: menu, data e preparação de mensagem WhatsApp
- `assets/`: logotipo e ilustrações
- `PRODUCT.md` / `DESIGN.md`: decisões de produto e design
